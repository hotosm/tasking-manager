# Download services FAQ

This document answers common questions about HOT's Tasking Manager download services and the process we follow when publishing project data exports.

## What are download services?

Download services provide exports of Tasking Manager project data (for example GeoJSON or other formats) so partners and mappers can use completed mapping work in external tools and workflows.

## How do I request a download?

1. Open a GitHub issue in this repository describing the project ID(s), desired format, and intended use.
2. Include a contact email and any data-handling requirements (retention, sharing restrictions, etc.).
3. The HOT data team reviews the request against our internal checklist before preparing the export.

## What information should I include in a request?

- **Project ID(s)** and public project URL(s)
- **Export format** needed (GeoJSON, Shapefile, etc.)
- **Geographic or task filter** if you do not need the full project
- **Timeline** and whether the export is for one-time or recurring use
- **License acceptance** confirmation when the project uses a custom license

## How long does processing take?

Simple single-project exports are usually handled within a few business days. Large multi-project requests or custom formats may take longer; we will reply on the issue with an estimate.

## What license applies to exported data?

Exports inherit the license configured on the Tasking Manager project (typically ODbL for OpenStreetMap-derived data). Requesters must comply with that license and any additional project-specific terms.
