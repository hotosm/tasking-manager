## Investigación y Definición de Estrategia de Documentación: GitHub Wiki vs GitHub Pages

**Responsable:** *Dolly Yadhira Mollo Chuquicaña* 

Investigar y comparar las herramientas GitHub Wiki y GitHub Pages con el propósito de definir una estrategia de documentación técnica y funcional adecuada para el proyecto.

### Descripción

La tarea consiste en realizar un análisis comparativo entre GitHub Wiki y GitHub Pages considerando criterios técnicos, colaborativos y de mantenimiento. El objetivo es determinar cuál herramienta resulta más apropiada según las necesidades actuales y futuras del proyecto.

La investigación deberá contemplar tanto documentación técnica interna como documentación pública, manuales, guías y documentación funcional.

### Responsabilidades

* Investigar el funcionamiento de GitHub Wiki.
* Investigar el funcionamiento de GitHub Pages.
* Comparar capacidades técnicas y colaborativas.
* Evaluar facilidad de mantenimiento y escalabilidad.
* Analizar integración con repositorios y flujo de desarrollo.
* Identificar ventajas, desventajas y limitaciones.
* Proponer una estrategia de documentación oficial para el proyecto.
* Definir posibles estructuras o convenciones de documentación.

### Alcance mínimo

El análisis deberá incluir:

* Casos de uso ideales para cada herramienta.
* Soporte para documentación técnica y funcional.
* Control de versiones y colaboración.
* Personalización y despliegue.
* Facilidad de navegación y organización.
* Curva de mantenimiento.
* Compatibilidad con documentación futura del proyecto.

### Entregables

* Informe técnico comparativo entre GitHub Wiki y GitHub Pages.
* Tabla comparativa de funcionalidades.
* Recomendación técnica final argumentada.
* Propuesta de estructura inicial de documentación.
* Conclusiones y lineamientos de uso.

### Criterios de aceptación

* La comparación contempla criterios técnicos y colaborativos relevantes.
* Se justifica claramente la recomendación final.
* El documento presenta ventajas y limitaciones de ambas soluciones.
* Se propone una estrategia de documentación coherente con el proyecto.
* La investigación es suficientemente detallada para soportar decisiones futuras.
